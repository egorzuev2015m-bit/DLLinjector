# 🚀 DLL Injector v2.0

**Простой, надёжный и визуальный инструмент для внедрения динамических библиотек (DLL) в процессы Windows.**

---

## 📌 Описание

**DLL Injector v2.0** — это легковесное Windows-приложение с интуитивно понятным интерфейсом, предназначенное для быстрого и безопасного инжекта DLL-файлов в работающие процессы. Подходит для разработки, тестирования модов, отладки и образовательных целей.

Приложение позволяет выбрать процесс из списка, указать путь к DLL и внедрить её одним нажатием кнопки.

---

## 🎯 Основные возможности

- 🔍 **Просмотр активных процессов** — все запущенные приложения отображаются в выпадающем списке с указанием PID.
- 🔄 **Обновление списка в реальном времени** — кнопка *Update* позволяет обновить перечень процессов без перезапуска программы.
- 📁 **Удобный выбор DLL** — встроенный диалог выбора файла (кнопка *Browse...*).
- 💉 **Инжект одной кнопкой** — внедрение происходит в один клик, со статус-индикацией каждого этапа.
- ⚡ **Работа с правами администратора** — гарантирует доступ к защищённым процессам.
- 🧩 **Поддержка x86 и x64** — инжектор собирается под любую архитектуру.
- 🛡️ **Обработка ошибок** — все этапы инжекта сопровождаются проверкой и выводом статуса.

---

## 🖼️ Интерфейс

- Поле выбора процесса (выпадающий список)
- Кнопка обновления списка (`Update`)
- Поле ввода пути к DLL (или выбор через `Browse...`)
- Кнопка инжекта (`INJECT`)
- Строка статуса в нижней части окна

---

## 📦 Пример использования

1. Запусти `Injector.exe` **от имени администратора**
2. Нажми `Update`, чтобы обновить список процессов
3. Выбери нужный процесс (например, `notepad.exe`)
4. Нажми `Browse...` и укажи свою DLL
5. Нажми `INJECT`
6. Убедись, что в строке статуса появилось сообщение `[+] Successfully injected!`
